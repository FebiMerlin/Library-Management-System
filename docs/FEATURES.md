# Перечень реализованных фичей

Согласован PM с Dev (задача T22). Каждая фича закрывает пункт из `docs/ISSUES.md` §2 и покрыта тестами из `docs/TESTS.md`.

## F1. Хранение данных в файле

**Проблема:** в исходном проекте все данные терялись при выходе (ISSUES 2.1).

**Реализация:** `include/lms/storage.h`, `src/core/storage.cpp`.
* Файл `library.dat` (путь задаётся `--data <file>`) загружается при старте; если файла нет — библиотека заполняется стартовым каталогом из 15 книг.
* Сохранение после **каждой** успешной операции и при выходе — потеря данных при аварийном завершении ограничена последней операцией.
* Запись атомарная: сначала во временный файл `library.dat.tmp`, затем переименование.
* Повреждённый файл → программа не стартует и печатает `Cannot load library.dat: Data file, line N: …` (не молча теряет данные).

**Формат файла** — текстовый, табуляция как разделитель, одна запись в строке:
```
LMS<TAB>1                                   заголовок и версия формата
BOOK<TAB>isbn<TAB>title<TAB>author<TAB>issuedTo<TAB>issuedOn
STUDENT<TAB>roll<TAB>name<TAB>balanceCents
TX<TAB>roll<TAB>day<TAB>type<TAB>amountCents<TAB>balanceAfterCents<TAB>isbn
```
`issuedTo` = 0 — книга на полке; `day`/`issuedOn` — дни с 1970-01-01; `type` ∈ {OPEN, DEPOSIT, ISSUE, RETURN, FINE, CLOSE}. Названия и имена не могут содержать табуляцию (проверяется при вводе).

**Как показать:** зарегистрировать студента, выйти, запустить снова — студент на месте (`cli.script.persistence`).

## F2. Возврат книг, сроки и штрафы

**Проблема:** README обещал 10-дневный срок и штрафы, в коде не было даже возврата (ISSUES 1.7, 2.2).

**Реализация:** `Library::issueBook / returnBook / daysOverdue / overdueBooks / booksIssuedTo`.
* При выдаче фиксируется дата (`Book::issuedOn`) и заёмщик (`Book::issuedTo`); плата $2.
* Не более 3 книг на студента (`Config::maxBooksPerStudent`).
* Возврат: `Student menu → 4. Return a book`. Если прошло более 10 дней (`Config::loanPeriodDays`) — штраф $1 за каждый день (`Config::finePerDay`), списывается с баланса, баланс может уйти в минус (долг покрывается залогом).
* Администратор: `8. Overdue report` — список просроченных книг с числом дней; в списках книг просроченные помечены `OVERDUE N day(s)`.
* Для демонстрации без ожидания 10 дней — ключ `--today YYYY-MM-DD`.

## F3. Поиск книг

**Проблема:** студенту показывался весь каталог без возможности найти книгу (ISSUES 2.3).

**Реализация:** `Library::searchBooks(query, onlyAvailable)`.
* Подстрока в названии, авторе или ISBN, без учёта регистра.
* Администратор: `5. Search books` с фильтром «только доступные». Студент: при выдаче (`3. Issue a book`) сразу вводит поисковый запрос, показываются только доступные книги.

## F4. Удаление книги и закрытие счёта студента

**Проблема:** ничего нельзя было удалить; лимиты заполнялись навсегда, залог $30 не возвращался (ISSUES 2.4).

**Реализация:** `Library::removeBook`, `Library::closeAccount`.
* `Admin → 3. Remove book`: с подтверждением; выданную книгу удалить нельзя.
* `Admin → 9. Close student account`: с подтверждением; нельзя, пока у студента есть книги; программа печатает сумму к выдаче = баланс + залог $30 (баланс может быть отрицательным из-за штрафов — тогда залог его покрывает).

## F5. История операций (выписка по счёту)

**Проблема:** невозможно объяснить, откуда взялся баланс (ISSUES 2.5).

**Реализация:** `Transaction`, `Library::history(roll)`, `Library::transactions()`.
* Каждая успешная операция записывается: дата, тип, сумма (со знаком), баланс после операции, ISBN (если о книге).
* Студент: `5. Account statement`; администратор: `7. View student account` показывает счёт и выписку.
* История сохраняется в файле данных (записи `TX`).

## Дополнительно (не считаются фичами, сделаны в рамках исправления ошибок)

* Валидация всего ввода (`Console`), меню не «вылетают» после одного действия.
* Пароль администратора из переменной окружения `LMS_ADMIN_PASSWORD`.
* Деньги в центах (`Money`), даты в днях (`Day`), настройки в `Config`.
* Реальный стартовый каталог вместо 15 заглушек «Title / Author».
* Ключи командной строки `--data`, `--today`, `--no-save`, `--version`, `--help`.
