# Сценарий сдачи проекта Заказчику

Проводит PM, длительность ≈ 25 минут. Перед демонстрацией: чистая машина (или чистый каталог), установлены git, CMake ≥ 3.21, компилятор, Ninja; интернет для скачивания GoogleTest.

## Шаг 1. Журнал ревизии (3 мин)

Открыть `docs/ISSUES.md`. Показать 2–3 проблемы с доказательством на **исходном** коде:

```bash
git show 0197b50:main.cpp > /tmp/orig.cpp && g++ -std=c++17 -o /tmp/orig /tmp/orig.cpp
printf '1\npassword\n1\n0\n' | /tmp/orig        # 1.1: "Book limit reached" при пустой библиотеке
printf 'abc\n' | /tmp/orig                        # 1.3: нечисловой ввод — молчаливый выход
```

## Шаг 2. Сборка с нуля (4 мин)

```bash
git clone <url-форка> lms && cd lms
cmake --preset release
cmake --build --preset release
```

Ожидаемо: в конце сборки — `Running test suite` … `100% tests passed, 0 tests failed out of 65`. Объяснить: цель `run_tests` входит в `ALL`, упавший тест = упавшая сборка. Показать, как отключить: `-DLMS_RUN_TESTS_ON_BUILD=OFF`.

Показать намеренно упавший тест (по желанию Заказчика): изменить ожидание в `tests/test_money.cpp`, пересобрать — сборка красная; вернуть.

## Шаг 3. Тесты отдельно (2 мин)

```bash
ctest --preset release                              # все 65
build/release/tests/lms_tests --gtest_filter='Loans.*'   # только выдача/возврат
```

Открыть `docs/TESTS.md`: соответствие тестов багам и фичам.

## Шаг 4. Демонстрация фичей (8 мин)

```bash
export LMS_ADMIN_PASSWORD=demo          # Windows PowerShell: $env:LMS_ADMIN_PASSWORD="demo"
build/release/lms --data demo.dat --today 2026-09-14
```

| # | Действия | Что показывает |
|---|---|---|
| 4.1 | `2` → номер `230001` → `y` → имя → депозит `100` | Регистрация; баланс $50.00 (100 − 20 − 30) |
| 4.2 | `3` → запрос `stroustrup` → ISBN `1001` | **F3 поиск**; выдача, баланс $48.00 |
| 4.3 | `3` → пустой запрос → `1002`; ещё раз `1003`; попытка четвёртой `1004` | Лимит 3 книги (**F2**) |
| 4.4 | `5` | **F5 выписка**: OPEN, ISSUE × 3 |
| 4.5 | `0` → `0` (выход) → `cat demo.dat` | **F1 файл данных**, читаемый формат |
| 4.6 | Запуск с `--today 2026-10-01` → `2` → `230001` → `4` → `1001` | **F2 возврат с просрочкой**: 17 дней − 10 = 7 дней, штраф $7.00 |
| 4.7 | `4` → `1002`, затем `4` → `1003` | Возврат остальных книг — тоже просрочены, штраф за каждую; баланс уходит в минус (долг) |
| 4.8 | `0` → `1` → пароль `demo` → `8` | Отчёт о просрочке (пусто после возвратов); `4` — весь каталог |
| 4.9 | `3` → `1015` → `y` | **F4 удаление книги** |
| 4.10 | `9` → `230001` → `y` | **F4 закрытие счёта**: сумма к выдаче = баланс + $30 |
| 4.11 | `7` → `230001` | Студент не найден — счёт закрыт; `6` — список пуст |
| 4.12 | Ввести `abc`, `99`, пустую строку в любом меню | Валидация ввода (баг 1.3) |
| 4.13 | `0` → `1` → пароль `password` | Отклонён — пароль не захардкожен (баг 1.6) |

## Шаг 5. Код и регламент (3 мин)

* Структура: `include/lms` (ядро без I/O) — `src/core` — `src/cli` — `tests`.
