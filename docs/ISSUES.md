# Журнал ревизии исходного кода

**Проект:** Library Management System (форк [abdulsamie10/Library-Management-System](https://github.com/abdulsamie10/Library-Management-System))
**Ревизия проведена:** 14.09.2026, ветка `main`, коммит `0197b50` (исходный `main.cpp`, 312 строк)
**Метод:** чтение кода, сборка `g++ -std=c++17 -Wall -Wextra -Wpedantic -Wshadow -Wconversion`, ручное воспроизведение на собранном бинарнике.

Обозначения серьёзности: **Крит.** — некорректная работа/UB/потеря данных; **Высок.** — функция не работает или уязвимость; **Средн.** — неправильное поведение в частных случаях; **Низк.** — качество кода, сопровождаемость.

## 5. Наблюдения при сборке

* `g++ 16.1 -Wall -Wextra -Wpedantic -Wshadow -Wconversion`: предупреждений нет — код формально «чистый», но именно поэтому статический анализ не заменяет ревизию: ни одна из проблем разделов 1–2 компилятором не обнаруживается.
* Проект собирается одной командой `g++ main.cpp`, но это не задокументировано.
